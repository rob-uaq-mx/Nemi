Nemi

Un lenguaje de pseudocódigo con palabras clave en español, para aprender a programar desde cero — y de paso, matemáticas discretas.

función mcd(a, b)
    mientras b ≠ 0
        t ← b
        b ← a mod b
        a ← t
    fin mientras
    regresa a
fin función
